# Images

Drop your own photos here to replace the CSS placeholders. All are optional —
the site looks complete with misty gradient placeholders until you add them.

| File                 | Used in            | Recommended size |
| -------------------- | ------------------ | ---------------- |
| `hero.jpg`           | Hero background     | 2000 × 1200 px   |
| `gallery/1.jpg`..`4` | About gallery       | 800 × 1000 px    |
| `projects/1.jpg`..`3`| Project cards       | 1200 × 750 px    |

After adding `hero.jpg`, set the `.hero__photo` opacity to `1` in
`src/components/Hero/Hero.scss` to reveal it beneath the fog.
