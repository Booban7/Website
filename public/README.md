# Images

Drop your own art here to replace the CSS placeholders. All are optional — the
site works with themed gradient placeholders until you add them.

| File                  | Used in       | Recommended size |
| --------------------- | ------------- | ---------------- |
| `gallery/1.jpg`..`4`  | About gallery  | 800 × 1000 px    |
| `projects/1.jpg`..`3` | Project cards  | 1200 × 750 px    |

Tip: use imagery that suits both alignments, or swap art per theme in the
components if you want distinct visuals for good vs. evil.
